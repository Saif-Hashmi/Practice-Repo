## Reporting a Vulnerability

We take the security of this project seriously. If you discover a security vulnerability, please follow these steps to report it responsibly:

1. **Do not** open a public GitHub Issue for security vulnerabilities.
2. Report the issue privately via [GitHub Private Vulnerability Reporting](https://github.com/Umar-Adnan/Practice-Repo/security/advisories/new) or contact the maintainers directly.
3. Include as much detail as possible:
   * A clear description of the vulnerability and its potential impact.
   * Step-by-step instructions to reproduce the issue.
   * Any relevant logs, screenshots, or proof-of-concept code.

### What to Expect

* **Acknowledgment:** You will receive a response acknowledging your report within **48 hours**.
* **Investigation:** We will investigate the issue and keep you updated on our progress.
* **Resolution:** Once verified, we will work on a patch and coordinate disclosure with you once the fix is released.

## Security Best Practices for Contributors

* Never commit API keys, tokens, passwords, or `.env` files to the repository.
* Keep dependencies up to date and review third-party packages before adding them.
* Always submit changes through Pull Requests for peer review.
